## Descripción

Cryptography can be easy, do you know what ROT13 is?

`cvpbPGS{abg_gbb_onq_bs_n_ceboyrz}`
## Solución

Se identificó que el mensaje proporcionado por el reto estaba cifrado mediante **ROT13**, un método de sustitución que desplaza cada letra 13 posiciones dentro del abecedario.

Para descifrarlo, se utilizó Python desde la terminal de Kali Linux, importando la librería `codecs`, que permite aplicar la transformación ROT13.

Se ejecutaron los siguientes comandos:
```python
import codecs

mensaje = "cvpbPGS{abg_gbb_onq_bs_n_ceboyrz}"

print(codecs.decode(mensaje, "rot_13"))
```

Al ejecutar el código, se obtuvo el mensaje original, revelando directamente la bandera:

```
academy {not_too_bad_of_a_problem}
```

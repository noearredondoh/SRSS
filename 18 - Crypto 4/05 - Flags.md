## Descripción

What do the [flags](https://challenge-files.cylabacademy.net/library/187296d0c352a8451662153842fc9794b9f247a1ac949978113ddfcb9a1bb76f/flag.png) mean?

## Solución

- Se descargó el archivo `flag.png`, el cual contenía una secuencia de banderas de diferentes colores y patrones.

- Se analizaron las pistas del reto, identificando que las imágenes correspondían al **Código Internacional de Señales Marítimas**.

- Se abrió la imagen desde la terminal de Kali Linux utilizando el comando `xdg-open flag.png`.

- Se utilizó como referencia el alfabeto de banderas marítimas, donde cada bandera representa una letra o un número.

- Se compararon las banderas de la imagen con el código de señales, descifrando el mensaje de izquierda a derecha.

- Finalmente, se obtuvo el mensaje `F1AG5AND5TUFF`, el cual se colocó dentro del formato solicitado por el reto para obtener la bandera.
```
picoCTF{F1AG5AND5TUFF}
```
## Notas adicionales

**Código Internacional de Señales Marítimas:** Es un sistema de comunicación visual utilizado principalmente en la navegación. Emplea banderas de diferentes colores y patrones para representar letras, números y mensajes.

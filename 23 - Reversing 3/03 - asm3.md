## Descripción

What does asm3(0xc682a0b0,0xf2b059d1,0xccc1df85) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/9c1d403a72b67a2f8ea1eaec314c81ec2ee7b35b74e25a9d48718b9f5dfdc8a2/test.S)

## Solución

1. Se abrió el apartado **Source** del reto para obtener el código ensamblador de la función `asm3`.

2. Se identificaron los tres argumentos y sus bytes en memoria, considerando el orden little-endian utilizado por la arquitectura x86.

3. Se analizó la primera instrucción:
    ```asm
    xor eax,eax
    ```
    Esta operación inicializó el registro `EAX` en cero.

4. Se identificó la instrucción:
    ```asm
    mov ah,BYTE PTR [ebp+0xa]
    ```
    Se obtuvo el valor `0x82`, que se almacenó en el registro `AH`.

5. Se analizó el desplazamiento:
    ```asm
    shl ax,0x10
    ```
    Se desplazaron los bits de `AX` 16 posiciones a la izquierda. Al ser un registro de 16 bits, el resultado fue cero.

6. Se realizó la resta:
    ```asm
    sub al,BYTE PTR [ebp+0xf]
    ```
    El cálculo fue:
    ```text
    0x00 - 0xf2 = 0x0e
    ```
    El resultado se almacenó en `AL`.

7. Se realizó la suma:
    ```asm
    add ah,BYTE PTR [ebp+0xc]
    ```
    El cálculo fue:
    ```text
    0x00 + 0xd1 = 0xd1
    ```
    Los registros quedaron de la siguiente manera:
    ```text
    AH = 0xd1
    AL = 0x0e
    AX = 0xd10e
    ```

8. Finalmente, se aplicó la operación XOR:
    ```asm
    xor ax,WORD PTR [ebp+0x12]
    ```
    Los dos bytes de memoria formaron el valor `0xccc1`.
    El cálculo fue:
    ```text
    0xd10e XOR 0xccc1 = 0x1dcf
    ```

9. Se identificó que el resultado se encontraba en el registro `EAX`, que es el registro utilizado para devolver el valor de la función.
```
0x1DCF
```

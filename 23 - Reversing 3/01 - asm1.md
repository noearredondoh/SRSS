## Descripción

What does asm1(0xb70) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/7bd2ba26eb715164d134263eaa09ff953c1544b3078ca72579b5207204ecb67a/test.S)

## Solución

1. Se abrió el apartado **Source** del reto para obtener el código ensamblador de la función `asm1`.

2. Se identificó el argumento recibido por la función:
    ```asm
    cmp DWORD PTR [ebp+0x8],0x6af
    ```
    El argumento proporcionado fue `0xb70`.

3. Se comparó el argumento con `0x6af`. Como `0xb70` es mayor, se ejecutó el salto condicional `jg`, dirigiendo el programa a la instrucción `<asm1+37>`.

4. Se realizó una segunda comparación:
    ```asm
    cmp DWORD PTR [ebp+0x8],0xb70
    jne 0x11b3 <asm1+54>
    ```
    Como ambos valores eran iguales, el salto `jne` no se ejecutó.

5. Se identificó la operación matemática que modificaba el registro `eax`:
    ```asm
    mov eax,DWORD PTR [ebp+0x8]
    sub eax,0x17
    ```
    Se realizó la resta:
    ```text
    0xb70 - 0x17 = 0xb59
    ```

6. Finalmente, se identificó que la función devolvía el contenido del registro `eax` mediante la instrucción `ret`.
```
0xB59
```

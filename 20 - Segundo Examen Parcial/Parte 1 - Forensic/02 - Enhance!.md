## Descripción

Download this image file and find the flag.

- [Download image file](https://challenge-files.cylabacademy.net/library/83bfcd323363337f297f4d4ee3bff06df8564155aa2037148151710fa8baec04/drawing.flag.svg)
## Solución

**1. Descargar el archivo** Asegúrate de descargar el archivo a tu computadora usando el enlace de la plataforma.

**2. Leer el código fuente del SVG** Abre tu terminal en la carpeta donde guardaste la imagen y utiliza el comando `cat` para imprimir el contenido del archivo como si fuera un archivo de texto normal. Ejecuta: cat drawing.flag.svg Dentro del resultado de cat apareceran lineas que inician con { y terminan con } esas son las lineas donde estan nuestra bandera, solo que separada por espacios.

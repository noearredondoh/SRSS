## Descripción

A second message has come in the mail, and it seems almost identical to the first one. Maybe the same thing will work again. Download the message [here](https://challenge-files.cylabacademy.net/library/ceba1af4dd4ee542c226922acd536495ebe14c328fb6766ae3244de7d7deaa2e/message.txt).
## Solución

1. Se descargó el archivo `message.txt`, que contenía el mensaje cifrado.

2. Se visualizó su contenido mediante el comando `cat message.txt`, identificando que se trataba de un cifrado por sustitución.

3. Se utilizó la herramienta en línea **Quipqiup**, especializada en resolver cifrados de sustitución monoalfabética.

4. Se copió el mensaje cifrado y se introdujo en Quipqiup para realizar el análisis de frecuencias y patrones de palabras.

5. Se ejecutó la opción **Solve**, obteniendo diferentes posibles descifrados.

6. Se seleccionó el resultado número 0, ya que mostraba un mensaje coherente en inglés.

7. Finalmente, se identificó la bandera al final del texto descifrado.
```
academy{FR3QU3NCY_4774CK5_4R3_C001_26A742EB}
```
## Notas adicionales

**Cifrado por sustitución monoalfabética:** Es un método de criptografía clásica que reemplaza cada letra por otra siguiendo una correspondencia fija.

**Análisis de frecuencias:** Es una técnica de criptoanálisis que estudia la frecuencia y los patrones de las letras para identificar posibles sustituciones.

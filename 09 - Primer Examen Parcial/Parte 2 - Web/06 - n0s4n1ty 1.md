## Descripción

A developer has added profile picture upload functionality to a website. However, the implementation is flawed, and it presents an opportunity for you. Your mission, should you choose to accept it, is to navigate to the provided web page and locate the file upload area. Your ultimate goal is to find the hidden flag located in the `/root` directory. You can access the web application [here](http://xebec.cylabacademy.net:28128/)

## Solución

Para resolver el reto se siguieron estos pasos:

```
1. **Carga de archivo no sanitizado (_Unsanitized File Upload_):** Se identificó que el formulario de subida de imagen de perfil no validaba la extensión del archivo. Se subió un script en PHP (`simple-backdoor.php`) que ejecuta comandos del sistema mediante el parámetro HTTP GET `cmd`.
   
2. **Ejecución remota de comandos (_RCE_):** Al acceder a la ruta `/uploads/simple-backdoor.php?cmd=`, se confirmó la capacidad de interactuar con el sistema. Al consultar `whoami`, se verificó que el proceso corría bajo el usuario de servicio `www-data`.
   
3. **Escalación de privilegios:** Siguiendo la pista del reto, se revisaron los permisos de `sudo` ejecutando `sudo -l`. Se identificó una mala configuración que permitía al usuario `www-data` ejecutar cualquier comando como `root` sin contraseña (`NOPASSWD: ALL`).
     
4. **Obtención de la bandera:** Se listó el contenido del directorio con `sudo ls -la /root` para identificar el archivo objetivo y posteriormente se leyó con `sudo cat /root/flag.txt`, obteniendo la bandera final.
```
